# schedule.md - 개발 일정

## 0. 전제

- 기간: 2026-11-01 ~ 2026-12-01(최대). 일찍 끝나면 그대로 종료.
- 작업량: 하루 8시간 이상, 주말 포함.
- 순서: MVP를 먼저 배포한 뒤 이후 단계를 하나씩 추가(decisions 0장 4번).
- 각 단계는 완료 기준을 만족해야 다음 단계로 넘어감. 일정이 밀리면 뒤 단계부터 줄이고, MVP 범위는 줄이지 않음.
